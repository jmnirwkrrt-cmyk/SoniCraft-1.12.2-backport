# SoniCraft Legacy — Forge 1.12.2, P48

Неофициальный изменённый порт **SoniCraft 1.10.1 автора EnderPreston**.
Лицензия — CC BY-NC 3.0, как указано в исходном JAR. Авторы и ссылки:
LICENSE.MD. English documentation: README.md.

## Установка

Java 8, Minecraft 1.12.2, Forge 14.23.5.x, GeckoLib Forge 1.12.2 3.0.31.
Заменить предыдущий SoniCraft JAR; не устанавливать оба одновременно.
Advanced Rocketry необязателен. Перед обновлением сохранить резервную копию мира.
Механики предыдущих версий, включая дружбу, тискание и Tornado, сохранены.

## Изменения P48

- Обычная Эгг-пешка добавлена в дополнительный спавнер девяти городских и
  промышленных зон. В Green Hill, Emerald Hill и Seaside Hill появляется реже.
  Заячья разновидность появляется в Night Carnival, Casino Night и Studiopolis.
- Перенесены Eggrobo, Flapper и Battle Flapper: регистрация, яйца призыва,
  оригинальные модели/текстуры, адаптированный бой. Их учитывают обычные
  таблицы спавна, дополнительный спавнер и импорт сущностей структур.
  Полное совпадение ИИ с оригиналом пока не заявляется.
- Неудачные попытки дополнительного спавна больше не расходуют остаток общего
  лимита за текущий проход. Существующие настройки лимитов и интервала сохранены.
- Добавлены независимые маршруты размещения 14 зданий: Casino Night — 2,
  Night Carnival — 1, Star Light — 2, Chemical Plant — 3, Press Garden — 3,
  Scrap Brain — 3. Эти шаблоны уже присутствовали в порте, но теперь имеют
  отдельные точки появления и высоту относительно входа. Центральная структура
  города или арена больше не обязательна для их появления.
- Подключены оригинальные петли Green Hill/Emerald Hill и валун Angel Island,
  с исходными смещениями и требованиями к грунту. Список ещё не подключённых
  объектов, биомы которых пока не перенесены, приведён в asset_report.json.
- Биомы из палитры Острова Ангела исключены из обычного Overworld и палитры
  типа мира SoniCraft: джунгли острова, выжженные джунгли, Marble Garden,
  Carnival Night, Ice Cap, Launch Base, Mushroom Hill, Sandopolis, Lava Reef,
  а также Sky Sanctuary. Фильтр охватывает и ещё не зарегистрированные зоны.
  Биомы не удаляются из реестра; старые чанки и палитра самого Мобиуса сохранены.
- Множитель `overworld.frequencyMultiplierP48` уменьшает существующие веса
  зон: по умолчанию 1/3 с округлением и минимумом 1 для включённого биома.
  Значение 0 отключает добавление. Это относительный вес климатической группы,
  а не точный процент территории мира. Старый список биомов в конфиге не
  возвращает зоны Острова Ангела в эту регистрацию.
- ID Мобиуса для новых конфигураций — 1123 даже без установленного AR.
  Существующий ID автоматически не меняется. AR использует значения от 10000
  для звёзд, поэтому старому Мобиусу 11230 требуется миграция.

Постройки и биомы меняются только при новой генерации. Старые здания и арены
не удаляются. Ограничение P47: максимум одна арена на отдельный связный участок
биома, без обязательного появления, сохранено.

## Старый мир с Мобиусом 11230 и Advanced Rocketry

Просто менять mobiusId нельзя: игра обратится к другой папке измерения.
В архив входит инструмент Python 3.10+, создающий отдельную копию мира.
Перед запуском закрыть Minecraft/сервер. Убедиться, что ID 1123 не занят другим
модом или планетой AR. Примеры для Windows:

```bat
py -3 migrate_mobius.py "D:\Minecraft\saves\World" "D:\Minecraft\config\sonicraft.cfg"
py -3 migrate_mobius.py "D:\Minecraft\saves\World" "D:\Minecraft\config\sonicraft.cfg" --copy-to "D:\Minecraft\saves\World-P48"
```

Первая команда только проверяет и выводит отчёт. Вторая копирует всё сохранение,
переименовывает DIM11230 в DIM1123 внутри копии, исправляет распознаваемые ссылки
измерения в данных игроков, точках возрождения, данных мира и чанках. Создаёт
в новой папке файл `sonicraft.cfg.P48-migrated`. Его нужно установить вместо
`config/sonicraft.cfg`, затем открыть именно копию мира. Исходные мир и конфиг
не изменяются. Для другого свободного номера есть `--new ID` (2–9999).

Инструмент заранее проверяет NBT и регионы, отказывается от существующей папки
назначения или занятой папки измерения. Случайные числовые совпадения с ID
не заменяются. Обрабатываются стандартные именованные поля измерений, записи
возрождения Forge и ключи данных измерений. Произвольные форматы сторонних
модов универсально не поддерживаются. Конфигурация галактики AR и маршруты
уже созданных ракет/станций не редактируются — их надо проверить в копии.
Для отката остаются исходный мир и конфиг. Реального пользовательского мира
для сквозной проверки миграции не было.

## Архив исходников и сборка

Архив отражает фактический процесс разработки через последовательные патчи:

- `p48/` — текущие Java-исходники, ресурсы, ASM-патч, сборка, проверки и миграция.
- `historical/` — доступные исходники базы P27 и последующих локальных патчей.
- `embedded-source/` — исходные материалы, сохранённые внутри P47.
- `baseline/P47.jar` — точная база воспроизводимой сборки P48;
  `baseline/SHA256.txt` — контрольная сумма.

Это не единое полностью сведённое Gradle-дерево. Исторические исходники могут
предшествовать последующим изменениям байткода, поэтому собирать их все вместе
как актуальный проект нельзя. Текущая сборка применяет исходники P48 к точной
базе P47. Итоговый JAR предоставляется отдельно.

Нужны JDK 8, Python 3.10+, Forge 1.12.2 development JAR с MCP-именами,
GeckoLib 3.0.31, отображение MCP→SRG в TSRG и classpath зависимостей:
ASM/asm-tree, Gson, Guava, Netty, LWJGL, Vecmath, Log4j, Commons IO/Lang, Fastutil.
Сторонние бинарные зависимости не вложены.

```sh
bash p48/BUILD.sh baseline/P47.jar /path/forge-mcp.jar /path/geckolib.jar /path/output.tsrg '/path/deps/*' output/P48.jar
```

Скрипт проверяет SHA256 базы, компилирует Java 8, переводит имена в SRG,
применяет патч, проверяет ссылки методов и полей, целостность JAR, ресурсы,
миграцию на искусственном сохранении и загрузку геометрии/анимаций настоящим
GeckoLib. Готовые изменённые ресурсы входят в архив. Скрипты генерации ресурсов
документируют перенос; для повторного запуска им нужен исходный JAR SoniCraft
и соответствующее дерево исходных моделей.

Полноценная игровая проверка спавна, моделей, мультиплеера и всей сборки с AR
ещё требуется.
