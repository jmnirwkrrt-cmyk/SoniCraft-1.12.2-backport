# SoniCraft Legacy 1.12.2 — 0.1.14 Marble Dungeon Worldgen Alpha

## Содержание

- **Естественная генерация Marble Cave 1** в измерении Мобиус и только в Marble Zone. Схема случайного размещения перенесена из исходного `worldgen/structure_set/marble_cave_1.json`: `spacing=6`, `separation=4`, `salt=47938921` (приближённое воспроизведение определения кандидата для 1.12.2). На основе существующего сборщика создаётся структура из входа, центральной пещеры, туннеля, коридора и тупика.
- **Без принудительной генерации чанков:** якорная точка добавляется в список ожидания после `PopulateChunkEvent.Post`. Сервер проверяет сохранённые точки раз в 80 тиков и размещает комплекс только после загрузки всей требуемой области. Отдельный список завершённых точек не допускает повторного размещения. Оба списка сохраняются в `WorldSavedData` отдельного измерения.
- **Защита мира:** при незагруженной области установка откладывается, при неподходящих биомах, конфликтующих блоках, сундуках/других tile-entities, лавах и воде установка отменяется до изменения первого блока. Ванильные руды, песок и гравий теперь разрешены к вырезанию вместе с природным камнем, иначе сооружение почти всегда отклонялось бы.
- **Jigsaw final_state:** соединители в оригинальных шаблонах с `final_state=minecraft:air` заменяются воздухом, вместо того чтобы оставлять каменные пробки в месте стыка.
- **Три адаптированных механизма:** активный огнемёт обжигает существ перед собой, датчик приближения выдаёт редстоун-сигнал при игроке поблизости, дробилка наносит урон возле её блока. Все три имеют базовую игровую логику в 1.12.2, но ещё НЕ используют оригинальные анимации, механику тайминга или визуальные эффекты.
- **Настройка:** `structures.naturalMarbleDungeons=true` в `sonicraft.cfg` (можно выключить до создания нового мира). Изменение влияет на новые точки генерации; уже запланированные точки не удаляются из сохранения.

## Ограничения и риски

1. Сборка **не скомпилирована**: `./gradlew build` останавливается до Java-компиляции с `UnknownHostException: services.gradle.org`. **Нового игрового `.jar` нет**. Проверка запуска Minecraft, правдоподобности света, поведения редстоуна и нагрузки на сервер пока не выполнена.
2. Исходные 8 NBT-сущностей Marble Cave не спавнятся: перенос противников будет отдельной задачей. Дробилка остаётся кубической адаптацией, её 3D-анимация не перенесена.
3. Большое подземелье может вырезать тысячи блоков за один серверный тик после удачной предварительной проверки. На игровых серверах следует испытать генератор в копии мира; при необходимости ограничить размер партии до сегментов.
4. Генерация редких мраморных подземелий допускается только в новых чанках после обнаружения якорной точки. Кандидат может сохраняться, пока в памяти нет всей области; сохранённый ожидающий кандидат способен появиться позднее, в том числе после перезахода в мир. Уже созданные до этого обновления чанки **не сканируются** на предмет новых якорей.
5. Проверяется центральный биом каждого элемента, а не полная неизменность биома на каждом блоке. Полное поведение оригинального 1.20 генератора пока не воспроизведено.

## Проверка

- `python tools/verify_structure_archive.py`: 361 шаблон и 2 129 144 записи исходных блоков, индексы и размеры NBT.
- `python tools/verify_jigsaw.py`: 200 схем Marble Cave с ориентацией соединений и без пересечений объёмов.
- `python tools/check_worldgen_014.py`: проверки подключения событий, сохранения списка ожидания, исходных параметров размещения и ещё 500 схем без пересечений.
- `python tools/verify_marble_caves.py`: ресурсы и ID использованных в 11 шаблонах блоков, исходные 8 сущностей по-прежнему не перенесены.
- `java tools/check_java_syntax.java src/main/java src/test/java`: синтаксический разбор 76 Java файлов JDK 21, **без проверки типов Forge и без компиляции мода**.
- `./gradlew --offline --no-daemon build`: **неудачно, wrapper не может загрузить Gradle 4.9 с services.gradle.org**.

## Если доступна Java 8 и зависимости Gradle

В Windows запустить `BUILD_JAR_WINDOWS.cmd`, в Linux `BUILD_JAR_LINUX.sh`, затем после успешной сборки проверить новый JAR из `build/libs/` в тестовой копии Minecraft 1.12.2 + Forge + GeckoLib 3.0.31. Перед проверкой массовой генерации рекомендуется отдельно протестировать `/sonistruct dungeon preview` и `/sonistruct dungeon` в тестовом мире. С исходным релизом 0.1.13 этот патч совместим только на уровне исходников, не бинарного `.jar`.
