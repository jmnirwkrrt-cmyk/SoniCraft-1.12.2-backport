# SoniCraft Legacy 1.12.2 — 0.1.25: добивка геометрии и соединяемых элементов

## Изменения

- **37 новых блоков** (всего **1289** в реестре), источники моделей и текстур импортированы из SoniCraft 1.20.1.
- Перенесены два типа заборов, четыре варианта железных ограждений с соединением к соседям через стандартные `BlockFence`/`BlockPane` 1.12.2.
- Три типа запертых дверей адаптированы на `BlockDoor`: верхняя и нижняя половины хранят состояния раздельно, что позволяет получить 32 исходных визуальных комбинации без переполнения 4-битных метаданных. Обычное нажатие на дверь не открывает её; **редстоун остаётся упрощённой заменой оригинальных условий разблокировки**.
- Два вида лестниц (`magnet_piece_stairs`, `launch_base_rocket_thruster_top`): 40 комбинаций внешнего вида обрабатываются механикой `BlockStairs`, форма выводится по соседним блокам.
- Поддержан новый адаптер `facade_facingvariant` с шестью направлениями и двумя сохранёнными состояниями (12 метаданных) для камеры Studiopolis. Перенесены элементы казино, Oil Ocean, студии, фабрик, Launch Base и прочие детали с не более чем 16 сохраняемыми состояниями.
- Расширен перечень предупреждений об отсутствующем поведении интерактивных элементов. Декоративный слот-механизм **не** является работающим игровым автоматом, декоративная камера **не** является работающей системой наблюдения, а модель босса **не** является реализованной битвой.
- Обновлён каталог `/sonistruct palette` до списка 0.1.25. Ранее он ошибочно показывал каталог версии 0.1.20.

## Остаток

**341 из 361 NBT-шаблона** теперь не имеют неизвестных ID SoniCraft. Осталось **20 шаблонов** с **25 уникальными отсутствующими ID**. Эти шаблоны в основном требуют исходных боссовых триггеров, 24- и 40-состояний с нестандартными свойствами, жидкого масла, стен с высотой соединения и электроники. См. `CLOSING_GAPS_025.json`.

**NB:** счётчик — только покрытие ID. Оригинальные состояния сущностей, тайл-сущностей, жидкости, полноценные города, боссы и исходная игровая логика ещё не доведены и не проверены в Forge.

Успешно выполнены:

```

python tools/verify_023.py "/path/to/sonicraft-1.10.1-forge-1.20.1.jar"

java tools/check_java_syntax.java src/main/java src/test/java
```

Проверены **96 Java-файлов (синтаксически)**, **37 новых блоков**, **154 ссылки на модельные узлы**, **89 текстур**, 361 исходный NBT, мультимодели и исходные ключи вариантов. `BatchContent025Check` добавлен, но требует полноценного Forge classpath и пока **не запускался**.

Попытка `./gradlew --no-daemon compileJava` вновь завершилась `UnknownHostException: services.gradle.org` **до компиляции**. Поэтому в 0.1.25 **нет скомпилированного `.jar`**. При наличии Java 8 и сетевого доступа сборку можно запустить через `BUILD_JAR_LINUX.sh`, `BUILD_JAR_WINDOWS.cmd` либо GitHub Actions (обновлены версия артефакта и тесты до `batch025Check`).
