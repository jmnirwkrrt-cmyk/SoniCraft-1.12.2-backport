# SoniCraft 1.12.2 — 0.1.24: завершающий проход по специальным этапам

## Содержание

- **35 новых блоков** с исходными моделями и текстурами оригинального SoniCraft 1.20.1 (включая Blue Spheres, специальные этапы, электроловушки, контрольные точки, фрагменты заводов и Death Egg).
- **11 адаптированных механизмов** в `SpecialStageBlocks.java`: синие сферы превращаются в красные при контакте игрока; красные тормозят; жёлтые подбрасывают; бамперы отталкивают; up/down/reverse-панели меняют скорость; чекпоинты реагируют на наступание; два электрических блока причиняют урон.
- Все адаптации **не идентичны оригиналу**. Миниигровые правила, условия победы, выбывание, награды Изумрудами Хаоса, сохранение прогресса, боссовые сценарии, промышленная логика и часть визуальных эффектов по-прежнему отсутствуют.
- Исправлено преобразование 16-состояний у `StructureFacadeBlocks.Variant`: при чтении метаданных используется `&15`, а не `&7`.
- Исправлены состояния JSON для специальных up/down-блоков с адаптером на две версии метаданных.
- Структурные предупреждения `deferred` и `adapted` расширены на новые блоки: геометрия больше не выдаётся за завершённую механику.
- Новая проверка `tools/verify_024.py` и Forge-зависимый `batch024Check`.

## Проверки

Запущены и прошли:

```sh
python tools/verify_024.py /path/to/sonicraft-1.10.1-forge-1.20.1.jar
python tools/verify_022.py /path/to/sonicraft-1.10.1-forge-1.20.1.jar
python tools/verify_023.py /path/to/sonicraft-1.10.1-forge-1.20.1.jar
java tools/check_java_syntax.java src/main/java src/test/java
```

Полная сборка **не состоялась**. Попытка `./gradlew --no-daemon build batch024Check` завершилась ещё до компиляции на `UnknownHostException: services.gradle.org`. Для этой версии необходим полноценный Gradle/Forge classpath и локальная игровая проверка. **Игрового JAR в обновлении нет.**

## План завершения порта (до нововведений)

1. Получить и протестировать реальный JAR в Forge 1.12.2; устранить ошибки компиляции и запуска прежде, чем накапливать новые механики.
2. Перенести оставшиеся 62 ID и особенности их состояний (в особенности multipart, 24–40 вариантов, жидкости и блок-сущности) только с воспроизводимой логикой, либо явно отметить заведомо отложенное содержимое.
3. Завершить хотя бы основной игровой цикл оригинала: ключевые боссы, структуры, Суперформы, Изумруды, персонажи. Транспорт оставить заключительным этапом, как было согласовано.
4. После рабочего релиза начать малые нововведения — отдельными конфигурируемыми функциями, не нарушая совместимость сохранений.
