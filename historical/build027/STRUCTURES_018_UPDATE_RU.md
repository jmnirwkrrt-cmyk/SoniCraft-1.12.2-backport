# SoniCraft Legacy 1.12.2 — пакет 0.1.18 (архитектура и городские структуры)

Обновление исходников поверх **0.1.17**. Отдельная папка `src/main/resources/assets/sonicraft/structures_1201` содержит все 361 исходных NBT без редактирования. В `STRUCTURE_BULK_018_MANIFEST.json` перечислены 167 новых идентификаторов блоков и 52 ещё неполностью покрытых шаблона.

## Что перенесено

- **167 новых блоков** (всего 1100 зарегистрированных) с исходными моделями и текстурами. Среди них архитектура Studiopolis, Night Carnival, Scrap Brain, Green Hill, Mirage Saloon, Press Garden, Crisis City, Oil Ocean, Aquatic Ruin, Death Egg и Launch Base.
- **309/361** NBT-шаблонов не содержат отсутствующих *блоков SoniCraft* (было 285/361). Новые полностью покрытые по этим ID структуры включают: 4 участка улиц Studiopolis, две фабричные постройки Scrap Brain, башню Night Carnival, дорогу Crisis City, лавку попкорна, три птичьих тотема Mirage Saloon, 2 водоёма Aquatic Ruin, здание Star Light и др.
- **Двери** Scrap Brain, Night Carnival и Death Egg представлены адаптерами `BlockDoor` Minecraft 1.12.2 (не просто статические текстуры); исправлен клиентский выбор модели с учётом `powered`.
- Установлены метаданные поворотов для статических архитектурных блоков, столбов, дорог и декоративных элементов. Динамическая механика машин не воспроизведена.
- Естественная генерация небольших построек: тотем Green Hill, птичий тотем Mirage Saloon, фонарь Studiopolis, фонарь Night Carnival. Работает в ранее включённых биомах и только в новых чанках, при успешно пройденной проверке места. Крупные здания пока доступны через команду `/sonistruct place <template>` и не соединяются автоматически в города.
- `/sonistruct palette` теперь читает актуальный каталог `paletted_018.json` вместо устаревшего списка 0.1.15.
- Для фабрик Scrap Brain `minecraft:mangrove_button` из 1.20 адаптирован к обычной деревянной кнопке 1.12.

## Важные ограничения

- **309 — не число полноценных работающих сооружений**. Это покрытие реестра SoniCraft, не гарантия всех ванильных состояний Minecraft 1.20.1, анимаций, лута, логики машин, генерации или сущностей. Отдельные крупные NBT могут быть отклонены по лимиту размеров и проверке территории.
- Не перенесены функции боссов, мини-игр Blue Spheres, летательных и прочих транспортных средств, редстоун-головоломок, целых jigsaw-городов. Эти группы нельзя добавлять как декорации с ложной отметкой «готово».
- Для архитектурных блоков без старых аналогов приблизительно подобраны материал, твёрдость и форма коллизии. Вырезы и декоративные объекты могут пока иметь полноразмерные хитбоксы.
- **Компиляция и запуск в Minecraft не пройдены.** Местный Gradle Wrapper упирается в `java.net.UnknownHostException: services.gradle.org`. Журнал: `build-attempt-0.1.18.log`. Проверка Java — только синтаксический разбор, без типов Forge.

## Проверка

```bash
python tools/verify_018.py /путь/к/sonicraft-1.10.1-forge-1.20.1.jar
# Реальная сборка, если доступны Gradle и Forge-зависимости:
./gradlew --no-daemon build batch018Check
```

Для обычной локальной проверки в Windows: `BUILD_JAR_WINDOWS.cmd`. Системе сборки Forge 1.12.2 обычно требуется JDK 8; не путать с JDK 17, используемой в других проектах.
