# SoniCraft Legacy 1.12.2 — 0.1.12, Marble Cave geometry alpha

Сборка **не проверена на Forge/Minecraft**: в рабочем окружении отсутствуют Gradle 4.9 и нужные зависимости, а `services.gradle.org` не разрешается через DNS. В этом выпуске предоставлены исходники, но **не новый скомпилированный JAR**. Не подменять сборку 0.1.12 предыдущим `0.1.10-columns-alpha.jar`.

## Что изменено после 0.1.11

- +19 ID блоков для мраморных пещер, из них 14 — формы, декорации, ловушки или мониторы с адаптированным поведением; 5 — пока только визуальные блоки оригинальных механизмов.
- Состояния/модели/текстуры перенесены из оригинального SoniCraft 1.10.1 для Forge 1.20.1, с заменой путей текстур и адаптацией вариантов blockstate.
- Новые блоки включают `marble_zone_brick_pillar`, `marble_zone_stone_stairs`, `marble_zone_stone_slab`, `spikes`, `marble_chain`, `marble_zone_cave_wall_torch`, `marble_cave_window`, два вида `marble_mural`, три вида `item_box`, `yellow_spring` и `cave_chain` для отсутствующей в Minecraft 1.12.2 ванильной цепи.
- Шипы наносят урон, жёлтая пружина запускает сущность, мониторы при клике дают кольца / временный Resistance (приблизительный аналог защиты и неуязвимости), факел освещает. **Числа/поведение требуют сравнения с оригиналом**; это не окончательный перенос контроллеров.
- Заглушки с зарегистрированной геометрией для `marble_zone_stone_flamethrower_on`, `switch_detector`, `switch_marble`, `player_proximity_sensor_on`, `marble_crusher_cylinder` **не реализуют соответствующие механизмы**.
- NBT-адаптер распознаёт `minecraft:chain` как отдельную цепь порта, `minecraft:redstone_wall_torch` как вариант красного факела 1.12.2. У сундуков/раздатчиков возвращаются только совместимые таблицы добычи и `Items` (не полная NBT сериализация).
- Для `marble_cave`, `marble_cave_1`, четырёх коридоров, поворота, тупика, комнаты спавнера и двух туннелей больше нет **неперенесённых sonicraft ID в палитрах** (11 оригинальных NBT-шаблонов). Это не означает полноты механик или наличия автоматической генерации.
- `/sonistruct check <имя>` показывает раздельно `unmapped` и `incomplete mechanics`. `/sonistruct place <имя> ...` вручную ставит шаблон только при загрузке всех затронутых чанков, без спавна оригинальных сущностей и без соединения jigsaw. **Ставить только в резервной копии или тестовом мире:** блоки в выделенном объёме заменяются.

## Ограничения

- Jigsaw-соединения и генерация полного многочастного данжа на границе чанков пока отсутствуют. Пещеры не появляются естественно; старые структуры 0.1.11 и мраморные колонны остаются.
- Оригинальные сущности в этих 11 NBT — 8 шт. — пока не восстанавливаются; блоки ловушек с визуальной заглушкой не работают.
- Палитры обычных Minecraft-блоков и новые классы не удалось проверить внутри Forge. Возможны различия ориентации и отображения, особенно у настенных украшений, цепей, факелов, механизмов и у piston/redstone-блоков.
- Поскольку у 1.12.2 нет vanilla chain, `cave_chain` пока имеет форму/текстуру мраморной цепи.
- Остальные 289 исходных структур имеют как минимум один неперенесённый Sonicraft ID. Для них действует старое правило: если ID не найден, шаблон не размещается.

## Проверки без Gradle

```
python tools/validate_assets.py
python tools/verify_structure_archive.py
python tools/verify_marble_caves.py
```

Все три проверки пройдены в среде подготовки. Всего проверено 361 NBT и 454 блока/ресурсных графа. Для 11 шаблонов пещер 37 424 исходные записи блоков; это число включает воздух, структуpные маркеры и неработающие механизмы.

При наличии инструментов: запускать `./gradlew build structurePortCheck marbleCaveCheck` в `source/` с подходящим JDK и доступными кэшированными зависимостями. Проблема загрузки текущей среды зафиксирована в `source/build-attempt-0.1.12.log`.

Следующий этап — jigsaw-соединения, вынос многочастных данжей в отдельный генератор с сохранением границ между чанками, механизмы датчиков/ловушек и связанные бадники. Транспорт остаётся последним этапом.
