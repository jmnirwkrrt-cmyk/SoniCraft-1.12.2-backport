# SoniCraft Legacy Forge 1.12.2 — изменение 0.1.13 / Marble Cave assembly

**Тип поставки: проверенные статически исходники, НЕ готовый мод.** В этом окружении компиляция не началась: Gradle wrapper не смог разрешить `services.gradle.org` (лог `source/build-attempt-0.1.13.log`). `.jar` версии 0.1.13 отсутствует; архив не содержит замаскированного старого мода.

## Реализовано

1. Многочастная сборка Marble Cave через настоящий формат jigsaw-маркеров из 1.20.1 NBT (поля `pool`, `name`, `target`, `orientation`, `pos`), без публикации jigsaw-блоков в мире 1.12.2.
2. Точные пулы из оригинала: центральная `marble_cave_1`, вход `marble_cave_1_spawner`, `marble_cave_1_tunnel_1/2`, `marble_cave_1_hallway_1/2/3/4`, `marble_cave_1_hallway_end`. Компоненты остальных шаблонов (например, `marble_cave` и `marble_cave_1_hallway_turn`) доступны вручную, но не вписаны в оригинальные пулы.
3. Для каждой попытки используется один seed. Проверяются `orientation` маркеров, соответствие `target/name`, 4 поворота, ограничение высоты и отсутствие пересечений ограничивающих прямоугольных объёмов.
4. **Предварительная проверка ВСЕХ секций:** нужные чанки загружены, блоки в них заменяемы (натуральный грунт, камень, воздух), нет контейнеров/защищённых блоков и посторонних жидкостей. При обычном отказе ни один блок не заменяется. Форсированная загрузка чанков НЕ выполняется. Проверка не создаёт территории или структуры.
5. Новая команда оператора: `/sonistruct dungeon preview [x y z] [seed]` для просмотра перечня секций и `/sonistruct dungeon [x y z] [seed]` для сборки в уже загруженной зоне. Координаты — уровень входной площадки; центральная пещера начинается на 29 блоков ниже.
6. `switch_marble` теперь использует исходное свойство `blockstate` (0–3); когда живое существо наступает, состояние становится 2, затем сбрасывается. `switch_detector` читает надстоящий переключатель и выдаёт уровень редстоуна 15 при состоянии 2. У обоих заменены blockstate JSON-модели, чтобы варианты свойства были зарегистрированы в 1.12.2. Длительность нажатия (15 тиков) пока адаптирована.
7. Команда `/sonistruct check <имя>` и одиночное `/sonistruct place ...` по-прежнему работают. Существующие 361 исходных NBT не изменялись.

## Проверки

- `python tools/verify_jigsaw.py` — 200 схем соединения: минимум 3 элемента (фактически пять в проверенных случаях), правильное направление маркеров и отсутствие перекрытий. Примеры расположения для нескольких seed.
- `python tools/validate_assets.py` — 454 блока и ресурсы.
- `python tools/verify_structure_archive.py` — все 361 NBT читабельны.
- `python tools/verify_marble_caves.py` — 11 шаблонов пещер не имеют отсутствующих Sonicraft ID.
- Java 8 синтаксис всех 75 Java-файлов проверен через `JavacTask.parse()`. Это **не компиляция**, типы Forge/Minecraft не проверены.

## Ограничения

- **Естественная генерация многочастных пещер пока не подключена.** Специально не вставляем многочанковое подземелье из события `Biome.decorate`, где соседние чанки ещё не готовы: это вызывало бы неполные постройки или рекурсивную генерацию. Пока генерация только по команде и после загрузки всей области.
- Нужна проверка на реальном Forge 1.12.2. Названия и сигнатуры API, семантика платформы, реакция жидкостей/редстоуна, точность отображения повернутых моделей ещё не проверены.
- Изначальные 8 мобов/сущностей из Marble Cave и механизмы огнемётов, датчиков расстояния и цилиндрической дробилки остаются не реализованы. Для жёлтой пружины, шипов и мониторов используются предварительные адаптации 0.1.12.
- Даже при правильной схеме структуры могут не размещаться: занятые блоки, бедрок, жидкости и незагруженные чанки вызывают безопасный отказ. Работайте только с резервной копией мира.
- Старый мод `0.1.10` не является заменой собранного 0.1.13.

## Локальная сборка

Распаковать папку `source` из полного архива, установить JDK, подходящую для ForgeGradle проекта, обеспечить Gradle Wrapper / зависимости Forge и выполнить `./gradlew build` (Windows — `gradlew.bat build`). Исходный файл `BUILD_JAR_WINDOWS.cmd` также приложен. `.jar` после успешной сборки появится в `source/build/libs/`.
