# SoniCraft P46 поверх P45
Изменения: основания наземных сооружений продлеваются до земли в пределах настройки глубины (по умолчанию 48, существующее значение сохраняется). Колонны учитываются отдельно, включая узкие блоки. Плавающие острова, подземелья и озёра исключены.
Город больше не обрезается до первой части после 20 секунд ожидания чанков. Все четыре оригинальных здания Studiopolis дополнительно имеют собственные точки генерации; третье содержит стеклянные цистерны магазина попкорна. У пола магазина добавлены частицы попкорна.
Камера получила статическую геометрию из оригинального geo, включая перевёрнутое состояние; слежение камеры не реализовано. Чекпоинт Sonic 2 активируется при касании и сохраняет точку возрождения в текущем измерении. Исправлены исходные варианты модели. Светильник излучает свет 15. Исправлена потерянная ветка регистрации source_cutout: ранее эти блоки попадали в обычный полный куб. Теперь source_cutout блоки используют непрозрачность и полноту формы false с момента создания состояния.
Знак финиша студии перемещён с восточной входной плиты за западную дверь арены, на пол.
Обычная Egg Pawn добавлена отдельно от Egg Pawn Bunny: исходная модель, яйцо, стрельба. Естественный спавн сохранён как в оригинале: test_zone; Bunny остаётся в night_carnival_zone. Снаряд адаптирован под 1.12; исходное оружие как предмет не добавлено. /summon sonicraft:egg_pawn
Звук процесса тискания — ломание шерсти; звук кормления прежний.
Структурные изменения применяются к новым размещениям, существующие постройки не перестраиваются автоматически.
Проверки: Java 8 compile, ASM verifier + ссылка на методы/поля, архив и ресурсы. Полноценный тест в клиенте Minecraft не выполнен.
Сборка: BUILD.sh P45.jar mapped-forge.jar geckolib.jar MCP-to-SRG.tsrg tools-classpath output.jar. В окружении должны быть Java 8 и Python 3. Для регенерации ресурсов assets.py нужны исходный мод и base-mcp.jar P45; для model.py — декомпилированная исходная модель.
