# SoniCraft Legacy P42 — мобианцы и привязанность

Для Minecraft Forge 1.12.2. Основа: P41-frontier, включая его структуры и воздушные шары.

## Установка

Заменить предыдущий JAR SoniCraft Legacy файлом `sonicraft-legacy-1.12.2-0.1.27-p42-companions.jar`. Не оставлять две версии одновременно. GeckoLib остаётся обязательным. Carry On нужен только для поднятия мобианцев и тисканья; приручение работает без него. Сам Carry On изменять не требуется.

## Тисканье

1. Поднять мобианца обычным способом Carry On.
2. Нажать ПКМ без приседания. Запускается двухсекундное тисканье: покачивание поднятой модели у лица, похожее на движение руки при еде, и звук поедания. Это специальная анимация поверх рендера Carry On, а не превращение мобианца в еду.
3. После окончания мобианец появляется рядом, возникают сердечки и сфера с 1–10 единицами опыта.
4. Повторное тисканье этого мобианца доступно через 5 минут игрового времени. Кулдаун сохраняется в данных сущности, в том числе при повторной переноске и сохранении мира.

Shift+ПКМ сохраняет обычное размещение Carry On. Если вокруг нет безопасного свободного места, мобианец остаётся на руках: награды и кулдауна не будет. Сохраняются UUID, здоровье, имя, хозяин и остальные данные поднятого существа. Carry On не является обязательной зависимостью мода.

## Привязанность

Одно угощение из таблицы гарантированно привязывает мобианца к игроку. Появляются сердечки, после чего он следует за хозяином. Повторное угощение восстанавливает 4 единицы здоровья. В выживании расходуется один предмет; в творческом режиме предмет не расходуется.

ПКМ пустой основной рукой переключает режимы:

- **Следовать:** ходить за хозяином, защищать его от нападающих и помогать против его цели. При сильном отставании — безопасно телепортироваться поблизости в том же измерении, если найдено место.
- **Свободно бродить:** продолжать обычное поведение, не садиться на месте. Защита хозяина от ответных атак сохраняется.

Мобианец не выбирает хозяина целью, не наносит ему ударов и не мстит за полученный от него урон. Аналогичная защита действует для других мобианцев и приручённых животных того же хозяина. Другой игрок не может перепривязать его угощением или переключить режим. Приседание оставлено для взаимодействий Carry On. Владение и режим сохраняются в мире и при переноске.

## Угощения

| Мобианец | Предмет |
| --- | --- |
| Соник | Чили-дог |
| Тейлз | Мятная конфета |
| Наклз | Виноград |
| Эми, Крим | Мягкое мороженое |
| Шэдоу | Какао-бобы |
| Сильвер | Яблоко |
| Вектор | Жвачка |
| Руж | Алмаз, изумруд или сапфир |
| Биг | Сырая рыба |
| Блейз | Виноград |
| Эспио | Ломтик арбуза |
| Чарми | Шоколадное мороженое |
| Инфинит | Стейк |

Для Бига, Блейз, Эспио, Чарми и Инфинита это назначенные в P42 угощения, дополняющие существовавшие предпочтения. Сапфиры распознаются по OreDictionary `gemSapphire` либо по имени предмета `sapphire` / `sapphire_gem` в любом пространстве имён. Сапфировые блоки не принимаются. Эггман, Метал Соник и Омега не входят в список мобианцев этой механики.

## Проверка

Код скомпилирован Java 8 против классов Minecraft/Forge 1.12.2. Проверены байткод пяти добавленных/изменённых классов и 589 ссылок на методы и поля после преобразования имён в SRG. Архив проверен на дубликаты, целостность ZIP и сохранность остальных файлов P41. Клиент Minecraft в этой среде не запускался: работу анимации с установленной версией Carry On и поведение ИИ необходимо проверить в игре.

Рекомендуемая игровая проверка: приручить Тейлза, переключить оба режима, ударить его, проверить помощь против моба; поднять, потискать и повторно поднять; сохранить/загрузить мир и проверить хозяина и кулдаун. Повторить для Руж с сапфиром. На сервере дополнительно проверить взаимодействие двух игроков и отсутствие перепривязки.

## Исходники

`src/` содержит новые классы; `Patch.java` добавляет вызовы механик в существующий LegacyCharacter, сохраняя его остальной код. `Remap.java` преобразует MCP/SRG-имена с учётом наследования. `LinkCheck.java` проверяет ссылки и байткод. `pack.py` собирает JAR поверх точной P41. `BUILD.sh` описывает воспроизводимую сборку с внешними зависимостями; они не включены в архив исходников.
