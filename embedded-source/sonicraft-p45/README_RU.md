# SoniCraft Legacy P45 — исходные сооружения и декорации

Полная сборка поверх P44. Заменить прежний JAR; зависимости те же. Изменения P42–P44 сохранены.

Добавлена или исправлена генерация 13 видов исходных feature-шаблонов:

| Биом | Сооружения / декорации |
|---|---|
| Green Hill | Озеро с мостом, малая гора, тотем |
| Marble | Руины |
| Ice Cap | Яма |
| Sandopolis | Башня и площадка с препятствиями |
| Aquatic Ruin | Малая, большая и парящая платформы |
| Seaside Hill | Колонна |
| Mushroom Hill | Большой гриб |
| Hill Top | Лавовое озеро |

Отдельно подключена большая гора Green Hill: исходные spacing=18, separation=15, salt=1612021572. Она использует существующий генератор крупных комплексов. Остальные 13 типов используют собственную сохраняемую очередь небольших сооружений.

Часть этих шаблонов ранее отсутствовала в естественной генерации, часть уже имела упрощённые попытки размещения с другими частотами или высотой. Это не 14 совершенно новых файлов NBT: исходные файлы уже были вложены в порт. Работа касается их появления в мире и правил размещения.

Для 13 типов перенесены исходные rarity_filter, биомы, смещения, разрешённые повороты/зеркальное отражение, ignored_blocks и проверки грунта. Проверка would_survive для малой горы адаптирована к грунту ghz_grass. Вместо точного heightmap 1.20.1 используется поиск поверхности родного грунта биома, чтобы не ставить сооружения на кроны деревьев. Точное расположение по seed не совпадает с 1.20.1.

Шаблоны с маской воздуха не вырезают окружающую местность; шаблоны, сохраняющие воздух, вырезают предусмотренные комнаты. Парящая платформа не получает искусственный столб-фундамент. Зеркалятся состояния блоков и поддержанные сущности. Существующие ограничения на неперенесённые сущности и механику шаблонов остаются: этот патч не добавляет нового ИИ обитателей озёр или новых механизмов.

Убрано повторное размещение выбранных шаблонов старым обработчиком. Старые ограничения «ширина не больше 14» и обязательная почти идеально плоская площадка больше не применяются к этим 13 типам. Предварительная проверка сохраняет ограничения на высоту, загруженность чанков, тайловые сущности и замену искусственных блоков.

## Производительность и сохранения

Только новые чанки. Очередь хранится в данных измерения, переживает перезапуск; размещение ждёт загруженные соседние чанки, не загружая их принудительно. За секунду выполняется не более двух попыток размещения на измерение. Максимум 2048 ожидающих записей; при заполненной очереди новые заявки пропускаются. Поэтому итоговая плотность может быть ниже исходной из-за препятствий, незагруженных соседей и ограничения очереди.

Настройка structures.naturalSourceFeatures=false отключает эти 13 типов и обработку их очереди. Большая гора управляется прежней настройкой naturalCityComplexes. Чтобы изменения вступили в силу, перезапустить игру. Старые чанки и постройки автоматически не переделываются.

## Проверки и границы

Java 8: компиляция, проверка байткода и ссылок Minecraft/Forge/GeckoLib. Проверены палитры всех 13 шаблонов, зарегистрированные биомы, маски, границы NBT и новые правила генерации. Отдельный Java-тест сравнивает перенос координат для всех четырёх поворотов и двух зеркальных состояний с прямым преобразованием координат оригинала. Игровой запуск и визуальный осмотр генерации здесь не выполнены.

Полный перенос всех структур не завершён. В частности, структуры Lava Reef, Launch Base, Scorched Angel Island и отдельных специальных измерений зависят от отсутствующих в этом порте биомов/измерений. Они не включены в случайные чужие биомы.

Исходники и готовые изменённые ресурсы входят в SOURCE_PATCH. BUILD.sh принимает P44.jar, mapped-forge.jar, GeckoLib, MCP→SRG.tsrg, classpath зависимостей и путь итогового JAR. Нужны инструменты Java 8.
