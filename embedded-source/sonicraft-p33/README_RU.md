P33: освещение блоков на основе игрового JAR P32. Меняется только общий метод BulkBlocks.configure: для известных ID вместо эвристики имени используются значения из конструкторов оригинала 1.20.1. Неизвестные ID используют прежнее правило. Нулевое значение отключает установку света этим методом, не сбрасывая отдельную настройку специализированного конструктора. Изменение влияет на блоки, проходящие через этот метод; никакой гарантии, что все 168 ID используют его, не делается. Настройки прозрачности и динамические механизмы не переписывались. Принудительный пересчёт света старых чанков не добавлялся.
Проверка: Java 8, ASM BasicVerifier для методов BulkBlocks, изолированный запуск фактического байткода configure и emitsLight с проверкой 168 ID и двух случаев прежнего поведения. Это не загрузка Minecraft, не тест сохранения и не проверка клиентских шейдеров.
Воспроизведение: вход — P32; Patch.java и P33Light.java собираются javac Java 8 в classes с ASM 6.1.1 (core/tree/analysis). Запустить Patch с аргументами P32.jar classes/org/sonicraft/backport/BulkBlocks.class fixture/org/sonicraft/backport/BulkBlocks.class (родительские каталоги создать заранее). Скомпилировать исходники fixture с classpath fixture:classes, запустить org.sonicraft.backport.Test cases.txt с этим же classpath. assemble.py P32.jar P33.jar упаковывает выпуск. Таблица и исходники сохранены рядом; generate.py воспроизводит таблицу из декомпилированного реестра оригинала и списка блоков P32.
