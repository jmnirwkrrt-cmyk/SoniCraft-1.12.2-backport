# SoniCraft P47 — транспорт, структуры и загрузка ресурсов
Базовая версия: P46. Замените предыдущий JAR этим файлом; не ставьте оба одновременно.

## По приложенному latest(1).log
Все 106 ресурсов GeckoLib из ошибок FileNotFoundException присутствовали в P46. Вызов initialize() происходил в конструкторе мода, до готовности ресурс-паков. Он перенесён на FML initialization, после загрузки ресурсов. Ошибки не скрываются фильтром логов.
Заполнены отсутствующие варианты night_carnival_curtain_light, cpz_factory_pillar_corner, press_garden_redstone_bulb_detector, включая дополнительные значения метаданных, разрешённые классами порта. Существующие варианты сохранены.
В рецептах прописаны метаданные предметов для Forge 1.12, что устраняет Missing data для плит и ванильного песчаника.

## Постройки
Дом Бига подключён к генерации Green Hill, маски structure_block удалены. Его земляной холм размещается с заглублением основания на 10 блоков.
Мастерская Тейлза получила дополнительные более частые точки в Green Hill/Emerald Hill. Полоса и мастерская объединены в обязательный шаблон. На полосе появляется оригинальный самолёт Tornado.
Арены ограничены одной на отдельный связный участок биома, без гарантированной генерации. Участки определяются по соседним чанкам и биому их центров (4-связность), без загрузки самих чанков. Учитываются сохранённые маркеры старых боссов и уничтоженных боссов; старые лишние арены не удаляются. На огромных участках обход ограничен 8192 проверками: при неясном результате новая арена отклоняется, а не создаётся лишняя. Отдельные небольшие острова одного типа биома не объединяются радиусом. Ограничение применяется к размещению с параметром natural=true.
Изменённые шаблоны применяются к новым размещениям, старые здания не перестраиваются.

## Лифты
Входы всех зарегистрированных elevator-блоков с горизонтальным направлением используют общую полую форму с открытым входом и лестницей. Осевые трубы Casino Night открыты вдоль своей оси, включая floor_tube. Существующие лифтовые блоки получают это поведение после обновления.

## Самолёт «Торнадо» — первый этап
Оригинальные геометрия, текстура, анимации idle/fly. Один пилот; ПКМ — сесть. W/S — движение вперёд/назад, взгляд — направление, пробел — подъём, X — снижение (переназначается в управлении), Shift — покинуть самолёт. Без пилота самолёт опускается на землю. Shift+ПКМ по пустому приземлённому самолёту — забрать предмет с сохранением здоровья. Уничтоженный самолёт даёт железо, не дублирует целую машину.
Предмет sonicraft:tornado_item находится во вкладке транспорта. Адаптированный рецепт: верхний ряд 3 дубовые доски; средний железо–алмаз–железо; нижний красная пыль–пусто–красная пыль. /summon sonicraft:tornado
Движение рассчитывает сервер; пакеты управления принимаются только от текущего пилота. Устаревший ввод сбрасывается, чанки впереди принудительно не загружаются. Бустер и его GUI пока не перенесены.

## Проверки и сборка
Java 8; проверка байткода и всех ссылок на методы/поля; JSON/NBT/ZIP; тесты связности регионов; все 54 geo-модели и 54 файла анимаций загружены настоящим GeckoLib 3.0.31. Полноценное прохождение в Minecraft не выполнялось.
BUILD.sh P46.jar mapped-forge.jar geckolib.jar MCP-to-SRG.tsrg tools-classpath output.jar
В tools-classpath нужны ASM, Gson, Guava, Netty 4.1.9 LWJGL 2.9.4 и Vecmath 1.5.2. Исходные ресурсы и преобразования включены в архив.
