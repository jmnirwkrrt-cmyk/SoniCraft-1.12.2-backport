P37: Мобиус вращается вокруг соседней звезды Mobius Prime. Для межзвёздного перелёта из системы Верхнего мира используй станцию с варп-двигателем, затем ракету. Прямой вход через золотой портал при успешной регистрации в AR закрыт, обратный выход сохранён. Без AR или при невозможности регистрации остаётся обычный портал. Не меняй ID существующего сохранения. Для новых миров с AR нужен свободный ID 2..9999 (по умолчанию 1123).
Размер и температура новой звезды, радиус орбиты, плотность атмосферы, кислород, гравитация и сутки взяты из системы Верхнего мира. Измерение и его генерация остаются у SoniCraft. Существующая планета P36 снимается с прежней орбиты; второй экземпляр мира не создаётся.
Вернули звуки успешного запуска классической и современных прыжковых панелей из оригинального SoniCraft. Источники: JumpPanelClassicEntityLaunchProcedure, JumpPanelModernEntityWalksOnTheBlockProcedure и TrickJumpPanelModernEntityWalksOnTheBlockProcedure.
Проверены Java 8, API AR Reworked 2.2.19, миграция и повторная инициализация в изолированном тесте. Реальный полёт, загрузка сохранения в Minecraft и воспроизведение звука в клиенте не проверены.
